# ФИЗИКА + МУЗЫКА — Дыбыс пен құбылыс әлемі

Физика мен музыка сабағына арналған сайт: **Аудио**, **Видео**, **Суреттер** және
**Ойындар мен тәжірибелер** (кемпірқосақ симуляциясы, ауа райы саяхаты, домбыра шерт т.б.).
Мұғалім материалдарды өзі жүктейді, ал оқушылар мен кез келген келуші оларды
кез келген құрылғыдан тыңдап, көре алады.

**Технологиялар:** React 19 · TypeScript · Tailwind CSS 4 · Vite · Supabase (Storage, Database, Auth)

---

## Екі режим

| | Демо режим | Нақты сервер режимі |
|---|---|---|
| Қашан қосылады | `.env` файлында Supabase кілттері **жоқ** болса | `.env` файлында Supabase кілттері **бар** болса |
| Файлдар қайда сақталады | Тек осы браузерде (IndexedDB) | Supabase Storage серверінде |
| Басқа құрылғыда көріне ме | ❌ Жоқ | ✅ Иә, барлық жерде |
| Мұғалімнің кіруі | `mugalim@demo.kz` / `demo1234` | Supabase Auth (сіз жасаған аккаунт) |
| Сайтта белгісі | Сары «Демо режим» жолағы | Жасыл «Сервер қосулы» белгісі |

Демо режим тек сайтты сынап көру үшін. Оқушыларға беру үшін міндетті түрде
нақты сервер режимін баптаңыз (төмендегі нұсқаулық).

---

## 1. Компьютерде іске қосу

Қажет: [Node.js](https://nodejs.org) 20 немесе жаңарақ нұсқасы.

```bash
cd music-space
npm install
npm run dev
```

Браузерде `http://localhost:5173` ашылады (әзірге демо режимде).

---

## 2. Supabase жобасын жасау

1. [supabase.com](https://supabase.com) сайтына тіркеліп, **New project** басыңыз.
2. Жоба атауын (мысалы `music-space`) және дерекқор құпиясөзін енгізіңіз, аймақ ретінде жақын аймақты таңдаңыз.
3. Жоба дайын болғанша 1–2 минут күтіңіз.

## 3. Дерекқор мен қойманы баптау

1. Supabase-те сол жақ мәзірден **SQL Editor → New query** ашыңыз.
2. Осы жобадағы `supabase/schema.sql` файлының **бүкіл** мазмұнын көшіріп қойыңыз.
3. **Run** басыңыз. «Success» хабарламасы шығуы керек.

Бұл скрипт мыналарды жасайды:

- `materials` кестесі — материалдың атауы, сипаттамасы, түрі, файл мекенжайы, жарияланғаны;
- `teachers` кестесі — мұғалімдер тізімі;
- `audio`, `video`, `images` атты үш Storage бакеті;
- қауіпсіздік ережелері (RLS): **көру — барлығына, жүктеу/өңдеу/өшіру — тек мұғалімге**;
- сервер жағындағы тексеру (төменде толығырақ).

## 4. Мұғалім аккаунтын жасау

1. **Authentication → Users → Add user → Create new user** басыңыз.
2. Мұғалімнің поштасы мен құпиясөзін енгізіп, **Auto Confirm User** белгісін қойыңыз.
3. **SQL Editor**-де мына сұранысты іске қосыңыз (поштаны өзіңіздікіне ауыстырыңыз):

```sql
insert into public.teachers (user_id)
select id from auth.users where email = 'mugalim@mektep.kz'
on conflict do nothing;
```

4. Бөгде адамдар тіркеле алмауы үшін: **Authentication → Sign In / Providers → Email** бөлімінде
   **Allow new users to sign up** параметрін өшіріңіз. (Тіркелген күннің өзінде де олар
   `teachers` тізімінде болмағандықтан ештеңе жүктей алмайды.)

## 5. Кілттерді қосу

1. **Project Settings → API** бетінен **Project URL** және **anon public** кілтін көшіріңіз.
2. Жоба папкасында `.env.example` файлын `.env` деп көшіріп, мәндерді толтырыңыз:

```env
VITE_SUPABASE_URL=https://abcdefgh.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
VITE_MAX_VIDEO_MB=50
```

> ⚠️ **`service_role` кілтін ешқашан** `.env` файлына немесе кодқа жазбаңыз.
> Сайтқа тек `anon public` кілті керек — ол ашық болуға арналған, ал қауіпсіздікті
> дерекқордағы RLS ережелері қамтамасыз етеді. `.env` файлы `.gitignore` арқылы
> GitHub-қа жүктелмейді.

3. `npm run dev` қайта іске қосыңыз. Жоғарғы жақта **«Сервер қосулы»** белгісі шығады.
4. **Мұғалім кіруі** → поштаңыз бен құпиясөзіңіз → **Материал жүктеу**.

---

## 6. Интернетке жариялау

### A нұсқасы — Vercel (ұсынылады, тегін)

1. Жобаны GitHub-қа жүктеңіз (`.env` файлы жүктелмейді — бұл дұрыс).
2. [vercel.com](https://vercel.com) → **Add New → Project** → GitHub репозиторийін таңдаңыз.
3. Framework: **Vite** (өзі анықтайды). Build command: `npm run build`, Output: `dist`.
4. **Environment Variables** бөліміне `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`,
   `VITE_MAX_VIDEO_MB` қосыңыз.
5. **Deploy** басыңыз. Бірнеше минуттан кейін `https://music-space-xxx.vercel.app` сілтемесін аласыз.

### B нұсқасы — Netlify (тегін)

1. [app.netlify.com](https://app.netlify.com) → **Add new site → Import an existing project** → GitHub.
2. Build command: `npm run build`, Publish directory: `dist`.
3. **Site configuration → Environment variables** бөліміне жоғарыдағы үш айнымалыны қосыңыз.
4. **Deploy site**.

### C нұсқасы — GitHub-сыз, қолмен

```bash
npm run build
```

Пайда болған `dist` папкасын [app.netlify.com/drop](https://app.netlify.com/drop) бетіне сүйреп апарыңыз.
(Бұл жағдайда `.env` файлы build алдында толтырылған болуы керек.)

Сайт жарияланғаннан кейін Supabase-те **Authentication → URL Configuration → Site URL**
өрісіне сайтыңыздың мекенжайын жазыңыз.

## Файл форматтары мен шектері

| Түрі | Форматтар | Ең үлкен көлемі |
|---|---|---|
| Аудио | MP3, WAV, OGG | 50 МБ |
| Видео | MP4, WEBM | 50 МБ (өзгертуге болады) |
| Сурет | JPG, JPEG, PNG, WEBP | 10 МБ |

**Тексеру екі деңгейде жүреді:**

1. **Браузерде** — файл таңдалған сәтте форматы мен көлемі тексеріледі, қате болса түсінікті хабар шығады.
2. **Серверде** — әр Storage бакетінде `allowed_mime_types` және `file_size_limit` бекітілген,
   сондықтан браузерді айналып өтсе де сервер рұқсат етілмеген файлды қабылдамайды.
   Сонымен қатар `materials` кестесіндегі триггер файлдың қоймада шынымен бар екенін тексеріп,
   оның нақты форматы мен көлемін Storage метадеректерінен алады.

**Видео шегін көбейту:** Supabase Free жоспарында бір файл 50 МБ-тан аспайды.
Pro жоспарында: `schema.sql` ішіндегі `video` бакетінің `52428800` санын өзгертіп
(мысалы `524288000` = 500 МБ), скриптті қайта іске қосыңыз, сосын
**Storage → Settings → Global file size limit** мәнін көбейтіп, `.env`-тегі `VITE_MAX_VIDEO_MB`-ны сәйкестендіріңіз.

## Мұғалімнің мүмкіндіктері

- **Материал жүктеу:** түрін таңдау → файлды сүйреп апару немесе таңдау → атауы, сипаттамасы →
  **Жүктеу**. Барысы пайызбен көрсетіледі. Видеоға мұқаба суретін қосуға болады;
  қоспасаңыз, ол видеодан автоматты түрде алынады.
- **Жариялау / жасыру:** әр карточкадағы 👁 батырмасы. Жасырылған материал («Жоба») оқушыларға көрінбейді.
- **Өңдеу:** атауын, сипаттамасын, жариялану күйін өзгерту.
- **Өшіру:** материал мен файл қоймадан біржола жойылады.
- **Басқару панелі:** барлығы / жарияланған / жобадағы материалдар саны және сүзгі.

## Оқушылар мен келушілер

- Тіркелусіз кіреді, тек жарияланған материалдарды көреді.
- Аудио: ойнату, кідірту, тоқтату, орнын ауыстыру, дыбыс деңгейі.
- Видео: ойнату, кідірту, тоқтату, орнын ауыстыру, дыбыс деңгейі, толық экран
  (пернелер: `Space` — ойнату, `F` — толық экран, `M` — дыбыс, `←/→` — 5 секунд).
- Суреттер: галерея, үлкейтіп ашу, келесі/алдыңғы сурет (батырма, `←/→` пернелері, телефонда саусақпен сырғыту).
- Іздеу және ең соңғы жүктелгендер алдымен.

## Жоба құрылымы

```
music-space/
├── index.html
├── package.json
├── vite.config.ts
├── .env.example              ← кілттер үлгісі (.env деп көшіріңіз)
├── supabase/
│   └── schema.sql            ← кесте, бакеттер, қауіпсіздік ережелері
└── src/
    ├── App.tsx               ← негізгі бет, күй және әрекеттер
    ├── index.css             ← түстер, анимациялар (Tailwind)
    ├── types.ts
    ├── lib/
    │   ├── repo.ts           ← режимді таңдау: демо немесе Supabase
    │   ├── supabaseRepo.ts   ← НАҚТЫ сервер: Storage + Database + Auth
    │   ├── demoRepo.ts       ← ДЕМО: тек браузер (IndexedDB)
    │   ├── config.ts         ← форматтар, шектер, тексеру
    │   └── media.ts          ← видео мұқабасы, бір уақытта бір ойнатқыш
    └── components/           ← Header, Tabs, AudioCard, VideoCard, VideoPlayer,
                                 ImageCard, Lightbox, UploadModal, EditModal,
                                 LoginModal, ConfirmDialog, EmptyState, Toasts …
```

## Жиі кездесетін қателер

| Хабарлама | Шешімі |
|---|---|
| «Дерекқор кестесі табылмады» | `supabase/schema.sql` іске қосылмаған |
| «Бұл аккаунтқа мұғалім рұқсаты берілмеген» | 4-қадамдағы `insert into public.teachers …` сұранысын орындаңыз |
| «Электрондық пошта расталмаған» | Users бөлімінде пайдаланушыны растаңыз (Auto Confirm) |
| «Файл көлемі сервердегі шектен асып кетті» | Файлды кішірейтіңіз немесе шекті көбейтіңіз (жоғарыдағы бөлім) |
| Сайтта әлі «Демо режим» тұр | `.env` дұрыс толтырылмаған немесе Vercel/Netlify-да айнымалылар қосылмаған; өзгерістен кейін қайта deploy жасаңыз |
| MP4 видео ойнамайды | Видео H.264 кодегімен сақталуы керек (көп телефон мен камера осылай жазады) |
